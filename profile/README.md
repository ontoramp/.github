OntoRamp is a governance maturity and enterprise-architecture assessment platform built
for the agentic-AI era. It maps an organization's governance documentation into a
structural graph and scores each of seven governance domains — Platform, Data,
Application, AI, Security, Governance, and Capability — on a five-level maturity scale,
turning policies, controls, and evidence into a computable picture of where governance is
strong, thin, or broken.

The same engine powers compliance gap analysis (SOC 2 readiness, ISO 27001 gap analysis,
NIST CSF), AI-governance readiness assessment for autonomous agents, technology due
diligence, board-ready governance posture reports, and standards-compliant ArchiMate 3.2
export.

**Every finding traces to structural evidence. Every recommendation traces to a documented
artifact.**

## Agent-native by design

The assessment tools are exposed over the **Model Context Protocol**, so AI agents
authenticate, discover, and call them directly — not just people at a keyboard.

| Server | What it does |
|---|---|
| [**graph-query**](https://github.com/ontoramp/ontoramp-graph-query) | Query an organization's architecture and governance constraints from any agent, with evidence chains |
| [**decision-intelligence**](https://github.com/ontoramp/ontoramp-decision-intelligence) | Log, evaluate, and ground consequential AI-assisted decisions against an authority context |
| [**knowledge-cartographer**](https://github.com/ontoramp/ontoramp-knowledge-cartographer) | Ingest documents into a governed knowledge graph; returns coverage maps and knowledge-health scores |

Each is a hosted, remote MCP server — nothing to install locally. A free developer tier is
available with a generous monthly allowance and no card required.

**Platform gateway:** `https://mcp.ontoramp.com/mcp` — Streamable HTTP, Bearer API key.
Get a key at [ontoramp.com/mcp](https://ontoramp.com/mcp).

> [!NOTE]
> [**transformation-radar**](https://github.com/ontoramp/ontoramp-transformation-radar) was
> retired as a standalone server. Its maturity-gap capability is served on the platform
> gateway above. The repository stays published for reference.
